# ASK Forge v6.0.0

## From v5.1 to v6.0.0

v5.1 made ASK Forge semantically smarter. OHDER gained semantic facts, governance validation, finding resolution, ranked refactor targets, patch-readiness checks, and council-lite architecture review.

v6.0.0 starts the language-agnostic foundation. The main shift is that ASK Forge now has compiled TypeScript contracts for the runtime shapes it already produces and the adapter/profile boundaries it needs before it can become portable across language ecosystems.

## What Changed

- Added TypeScript tooling and compile checks without rewriting the JavaScript runtime.
- Added contracts for current runtime artifacts: task board entries, plan batches, event records, and projection-facing state.
- Added typed event contracts for high-value ASK and OHDER runtime events.
- Added typed check and governance contracts for pre-commit, commit-msg, pre-push, OHDER architecture status, semantic facts, findings, and OFRR resolution records.
- Added the language adapter contract for install, format, lint, typecheck, test, build, detection, changed-file test mapping, and architecture inspection.
- Added project profile and law-pack contracts so future language/framework governance can be described before enforcement behavior changes.
- Added worker and queue contracts while preserving the current queue classes: planner, implementer, verifier, debugger, integrator, reviewer.
- Added portable JSON contract fixtures for runtime artifact families.

## Adapter Boundary

Node/JavaScript remains first. The v6.0.0 contracts prepare ASK Forge for language-agnostic governance, but Python, PHP, .NET, Java, C++, Go, Rust, and other non-Node adapters are not implemented in this release.

## Why It Matters

ASK Forge is moving from a Node-centered governance runtime toward a portable governed development platform. v6.0.0 does not complete that platform shift. It puts the house in order: stable contracts first, adapter implementations later.

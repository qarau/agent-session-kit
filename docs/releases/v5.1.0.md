# ASK Forge v5.1.0 Release Notes

## Summary

ASK Forge v5.1.0 is the OHDER semantic autonomy release. v5.0.0 made ASK Forge a governed autonomous execution control plane; v5.1.0 makes the architecture governance layer smarter, more semantic, and more explicit about the boundary between autonomous task creation and future autonomous patching.

## What Changed From v5.0.x

- Added normalized `semanticFacts` so OHDER analyzers produce consistent metric, value, confidence, severity, source, evidence, and recommendation envelopes.
- Added deeper semantic analyzers for SSoT, event-only synchronization, duplication, observability, testability, replaceability/YAGNI, and upgraded security boundary detection.
- Added OHDER mode profiles so `fast`, `strict`, and `refactor` have materially different governance behavior.
- Added `ask governance validate`, a mutating runtime command that recomputes architecture/entropy evidence and writes a replayable governance decision.
- Added ranked refactor `targetPortfolio` output with confidence, blast radius, freshness, reasons, and related slice evidence.
- Added `ohder_autonomy` policy for bounded autonomous refactor task creation.
- Added `OhderPatchReadinessGate` to evaluate whether a future patch would be safe to consider.
- Added deterministic `council-lite` architecture review evidence in architect status.

## Autonomy Boundary

v5.1.0 can autonomously create bounded refactor tasks when policy explicitly allows it. It does not apply patches automatically. Patch readiness is visible as governance evidence only, and current runtime output keeps patch execution disabled.

## Operator Impact

- Use `node ask-core/bin/ask.js governance validate` when `ask next` requests governance validation.
- Use `node ask-core/bin/ask.js refactor preview` to inspect selected target plus ranked portfolio before creating refactor work.
- Use `semanticFacts` and `architectureReview` in `ask architect status` to understand why OHDER reached a decision.
- Treat `OhderPatchReadinessGate` as future-autonomy evidence, not current patch execution.

## Why This Matters

ASK Forge is becoming a governed autonomous software development system: ASK is the governance constitution, Codex is the implementation engine, and Superpowers supplies workflow discipline. v5.1.0 strengthens the constitution by turning OHDER from heuristic checks into semantic, replayable, policy-aware architecture governance.

# ASK v4.0.0 Release Notes

**Release date:** 2026-05-07  
**Release type:** Major

## Summary

ASK v4.0.0 promotes the runtime-first architecture as the primary operating model, keeps strict git-hook enforcement, and introduces expanded orchestration/runtime intelligence in `ask-core`.

This release also simplifies repository packaging by removing legacy installer and session-kit helper surfaces from the v3 era.

## Highlights

- Expanded governed runtime command surface (continuation, intent, slice planning, metrics, resume packet)
- Stronger policy and dispatch orchestration for agent execution
- Improved runtime scaffolding and sequence-repair behavior
- Preserved commit/push enforcement via `.githooks` and session adapter wrappers
- Updated comprehensive v4 README with migration guidance

## Breaking Changes

- Removed legacy installer entrypoint (`install-session-kit.mjs`)
- Removed bundled `kit/` helper toolchain and associated session-doc workflow scripts
- Removed legacy autonomy and release-doc consistency wrapper scripts from repo root
- Removed v3-era release/doc bundles that no longer map to v4 packaging

## Migration Notes (v3 -> v4)

1. Replace installer-based rollout with vendor-copy of:
   - `ask-core/`
   - `.githooks/`
   - `scripts/session/installHooks.mjs`
   - `scripts/session/runAskCorePreCommitAdapter.mjs`
   - `scripts/session/runAskCorePrePushAdapter.mjs`
2. Run `node scripts/session/installHooks.mjs` in each target repository.
3. Verify `git config --get core.hooksPath` returns `.githooks`.
4. Validate policy flow using `ask preflight`, `ask can-commit`, `ask pre-commit-check`, and `ask pre-push-check`.

## Hook Enforcement Contract

- `.githooks/pre-commit` invokes `scripts/session/runAskCorePreCommitAdapter.mjs`
- `.githooks/pre-push` invokes `scripts/session/runAskCorePrePushAdapter.mjs`
- Non-zero adapter exits block git operations

## Verification Snapshot

- Runtime test suite: `107/107` passing in branch verification run
- CLI help surface confirmed for new command families
- Hook install path verified (`core.hooksPath=.githooks`)

## Affected Areas

- Runtime core and orchestration engine (`ask-core/src/core/*`)
- CLI command surface (`ask-core/src/cli/*`)
- Runtime projections/snapshots and policy registry
- Hook adapters and session integration wrappers
- Repository documentation and packaging layout

## Upgrade Recommendation

Adopt v4.0.0 as a planned major upgrade. Teams using v3 installer/session-doc utilities should schedule migration and onboarding updates before broad rollout.
